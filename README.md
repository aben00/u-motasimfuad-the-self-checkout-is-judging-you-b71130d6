One funny remark from a judgmental self-checkout machine, at most 200 characters — the sort of line the till would say to a shopper buying twelve yoghurts and nothing else.

> Twelve yoghurts and nothing else. I've scanned your whole personality — it expires before the yoghurts do.

Character count: 106.

## Run it

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and verifies it byte-for-byte, with a built-in gate self-check (1–200 characters, single line, non-blank).
